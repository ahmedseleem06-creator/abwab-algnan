# 🌙 تطبيق أبواب الجنان - Abwab Al-Jinan
### رفيقك الشامل للاستعداد لشهر رمضان المبارك (تطبيق ويب تقدمي PWA للهاتف والحاسوب)

---

## 🌟 مميزات التطبيق
1. **بطاقة العد التنازلي الملكية:** هلال ذهبي مائل ثلاثي الأبعاد مع حبيبات النجوم المتلألئة وخلفية إسلامية كحلية داكنة.
2. **متتبع العادات بالحلقات المزدوجة:** متابعة صلاة الفجر، السنن، قراءة القرآن، والأذكار مع رسوم بيانية تفاعلية.
3. **تحدي الـ 30 يوماً قبل رمضان:** تسجيل أيام الصيام الإثنين والخميس والأيام البيض.
4. **مخطط الوجبات وقائمة التسوق الذكية:** إدارة وجبات السحور والإفطار مع إمكانية إضافة وجبات مخصصة وتصدير مقاديرها إلى قائمة التسوق بضغطة زر.
5. **المصحف الشريف الإلكتروني:** قراءة السور (114 سورة) مع نظام العلامات المرجعية وحاسبة الورد اليومي لختم القرآن.
6. **مواقيت الصلاة والتنبيهات:** حساب أوقات الصلوات والإمساك والإفطار.
7. **المسبحة الإلكترونية ومستودع الأدعية:** تسبيح رقمي مع اهتزازات اللمس وأدعية مأثورة مع مؤقت للاستجابة.
8. **دعم كامل للعمل بدون إنترنت (Offline PWA):** عبر Service Worker وWeb App Manifest.

## 🚀 كيفية الرفع إلى GitHub

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في [GitHub](https://github.com/new).
2. افتح سطر الأوامر في مجلد المشروع، أو شغّل ملف `push_to_github.bat`:
```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git branch -M main
git push -u origin main
```

## 📱 كيفية تثبيت التطبيق على الهاتف واستخراج APK

### الطريقة الأولى: التثبيت المباشر بنقرة واحدة (PWA - الأسرع والأفضل)
1. في مستودع GitHub، ادخل إلى **Settings** > **Pages**.
2. تحت **Build and deployment**، اختر **Deploy from a branch**، ثم اختر الفرع `main` والمجلد `/ (root)` واضغط **Save**.
3. انتظر دقيقة واحدة حتى يظهر رابط موقعك المباشر، مثل:  
   `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/`
4. افتح هذا الرابط من هاتفك:
   - **على أندرويد (متصفح Chrome):** اضغط على قائمة الخيارات `⋮` ثم اختر **"تثبيت التطبيق" (Install app)** أو **"إضافة إلى الشاشة الرئيسية"**.
   - **على آيفون (متصفح Safari):** اضغط على زر المشاركة `⬆` بالأسفل ثم اختر **"إضافة إلى الصفحة الرئيسية" (Add to Home Screen)**.
5. سيظهر التطبيق فوراً على شاشة هاتفك بأيقونته الذهبية واسمه، ويعمل كأي تطبيق أصلي بدون شريط متصفح وبدون إنترنت!

---

### الطريقة الثانية: استخراج ملف APK للأندرويد
1. ادخل إلى موقع [PWABuilder](https://www.pwabuilder.com/).
2. ضع رابط تطبيقك على GitHub Pages واضغط **Start**.
3. سيتعرف الموقع تلقائياً على أيقونات التطبيق وملف `manifest.json`.
4. اضغط على خيار **Android** ثم **Download Package / APK** لتحميل ملف التطبيق وتثبيته مباشرة على أي هاتف أندرويد.
